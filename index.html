Backup & informasi penting

Aplikasi ini berjalan lokal, tanpa server dan tanpa sinkronisasi.

Jangan gunakan sebagai satu-satunya catatan transaksi usaha. localStorage dapat dihapus browser, tidak tersinkron, dan bukan database yang tahan gangguan. Unduh backup JSON dan simpan di lokasi terpisah secara rutin.

Backup / pemulihan

Ekspor menyimpan menu dan transaksi ke satu file JSON. Impor menggabungkan data unik dan tidak menghapus transaksi yang sudah ada.

Keterbatasan prototipe

  • localStorage khusus browser/origin dan perangkat ini; data dapat hilang bila data situs dihapus, browser di-reset, atau perangkat rusak.
  • QRIS dan pembayaran lain tidak terhubung ke penyedia pembayaran; status lunas harus diperiksa dan dicatat oleh staff.
  • Cetak menggunakan dialog print browser. Ukuran hasil bergantung pada browser, driver, dan pengaturan printer.
  • Aplikasi produksi perlu backend/database persisten, autentikasi, audit, backup terjadwal, sinkronisasi, dan prosedur pemulihan teruji.
